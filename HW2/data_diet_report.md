# Отчёт по воспроизведению результатов *Deep Learning on a Data Diet*

## Цель работы

Целью работы было частично воспроизвести эксперименты из статьи *Deep Learning on a Data Diet* и проверить, насколько можно сократить обучающую выборку CIFAR-10 без существенной потери качества. Основной интерес представляли методы оценки важности отдельных объектов обучающей выборки: **EL2N**, **Forgetting** и **GraNd**. В качестве контрольного метода использовалась случайная выборка (**Random**).

Полное воспроизведение исходного протокола статьи в Google Colab оказалось слишком затратным по времени (нужно было бы около 60 часов t4 GPU времени, а колаб дает в день максимум 5 часов) и вычислительным ресурсам. В оригинальной работе используются длительные запуски и несколько повторов с разными инициализациями, тогда как Colab накладывает ограничения на длительность сессий и доступное GPU-время. Поэтому экспериментальный протокол был упрощён так, чтобы один запуск занимал примерно **45 минут**. Кроме того, разные методы были распараллелены по отдельным Colab-сессиям, поскольку последовательный запуск всей серии занимал бы слишком много времени и быстро упирался бы в лимиты платформы.

## Экспериментальная установка

Использовался датасет **CIFAR-10**, содержащий 50 000 обучающих и 10 000 тестовых изображений десяти классов. В качестве модели использовалась **ResNet18**.

Для ускорения обучения размер batch был увеличен до **512**. Learning rate последовательно снижался по схеме:

`0.4 → 0.08 → 0.016 → 0.0032 → 0.0008`.

Переход на следующий learning rate выполнялся адаптивно по стабилизации train loss. Основные эксперименты проводились с **одним seed**, однако реализация позволяет задавать несколько seed и усреднять результаты.

Для каждого метода рассматривались подмножества размером **75%, 50% и 25%** от исходного train set. Отдельно обучалась модель на полном датасете, которая использовалась как baseline. EL2N, Random, Forgetting и GraNd запускались в отдельных Colab-сессиях, а результаты сохранялись в общую структуру на Google Drive.

## Оценка важности данных

**EL2N** измеряет расстояние между предсказанием модели и истинной меткой. Чем больше значение EL2N, тем сильнее модель ошибается на данном объекте и тем более сложным он считается. Для формирования подмножеств сохранялись объекты с наибольшими EL2N-score.

**Forgetting** считает количество случаев, когда объект, ранее классифицированный правильно, позже снова классифицируется неправильно. Большое число forgetting events указывает на нестабильные и сложные примеры.

**GraNd** оценивает важность объекта через норму градиента функции потерь по параметрам сети. Точный расчёт GraNd вычислительно дорог, поэтому в ускоренном эксперименте повторный расчёт не выполнялся. Использовались ранее рассчитанные значения **GraNd на 20-й эпохе**.

**Random** выбирает случайное подмножество данных и используется как базовый контрольный метод.



## Результаты

Baseline статьи был воспроизведен, для его подсчета нужно около 3-4 часов. Он составляет 95% test accuracy. Более оптимизированный подход к обучению работает по 45 минут и его baseline составляет около 92 %. Для воспроизведения результатов статьи был выбран именно он, так как он так же хорошо отражает результаты эксперимента. 

| Метод | Доля train set | Final test accuracy | Best test accuracy |
|---|---:|---:|---:|
| Full | 100% | **92.81%** | **92.85%** |
| Forgetting | 75% | **92.64%** | **92.71%** |
| EL2N | 75% | 92.48% | 92.56% |
| Random | 75% | 91.89% | 91.98% |
| GraNd | 75% | 91.37% | 91.45% |
| Forgetting | 50% | **92.19%** | 92.23% |
| EL2N | 50% | 91.57% | 91.67% |
| Random | 50% | 90.93% | 90.97% |
| GraNd | 50% | 89.76% | 89.76% |
| Random | 25% | **87.53%** | 87.71% |
| Forgetting | 25% | 83.94% | 84.06% |
| EL2N | 25% | 77.22% | 77.48% |
| GraNd | 25% | 74.15% | 74.57% |


При сохранении **75% данных** качество практически не отличается от baseline. Наиболее близкий результат показывает Forgetting, затем EL2N. Это соответствует идее статьи: если удалить в основном простые и избыточные объекты, можно уменьшить объём обучающих данных почти без потери качества.

При сохранении **50% данных** преимущество осмысленного отбора также сохраняется. Forgetting достигает **92.19%**, уступая полной выборке всего около **0.62 процентного пункта**. EL2N также оказывается лучше случайного отбора. Таким образом, при умеренном сокращении датасета методы оценки важности позволяют сохранить большую часть качества модели.

При сохранении только **25% данных** ситуация меняется. Лучший результат показывает Random, а EL2N и GraNd заметно ухудшаются. Вероятное объяснение состоит в том, что при слишком агрессивном сокращении выборки отбор только примеров с максимальными score приводит к переизбытку сложных, пограничных и потенциально нетипичных объектов. Такое подмножество хуже представляет исходное распределение CIFAR-10. Случайная выборка, напротив, даже при небольшом размере лучше сохраняет разнообразие исходных данных.

В целом результаты показывают, что подходы из *Deep Learning on a Data Diet* наиболее полезны при умеренном pruning. Для 50–75% данных EL2N и особенно Forgetting позволяют приблизиться к качеству обучения на полном датасете и превосходят случайный отбор. При слишком сильном сокращении до 25% простая стратегия выбора объектов с максимальными score перестаёт быть оптимальной.

Абсолютные значения accuracy ниже результатов исходной статьи, что связано с упрощённым вычислительным протоколом: меньшим числом повторных запусков, увеличенным batch size и ограничением каждого обучения примерно до 30–45 минут. Эти изменения были необходимы из-за ограничений Google Colab и позволили провести серию экспериментов на доступных вычислительных ресурсах.
